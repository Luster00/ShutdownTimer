# Shutdown Timer

Небольшое приложение для Windows, которое выключает (или перезагружает) компьютер по таймеру или в заданное время. Работает в системном трее, заранее напоминает о выключении и оставляет время, чтобы передумать.

## Возможности

- **Два способа задать время.** «Таймер» — через сколько выключить (часы и минуты, быстрые кнопки 15 мин, 30 мин, 1 час, 2 часа). «Точное время» — выключить в выбранное время; если оно сегодня уже прошло, сработает завтра.
- **Выключение или перезагрузка.**
- **Напоминания.** Уведомления Windows за 10, 5 и 1 минуту и за 30 секунд до конца. Отключаются тумблером.
- **Время на отмену.** После срабатывания таймера у вас есть 20 секунд, чтобы отменить выключение.
- **Запоминает настройки.** Режим, время, действие и напоминания восстанавливаются при следующем запуске.
- **Работа в трее.** Крестик сворачивает окно в трей, обратный отсчёт виден в подсказке значка.
- **Современный интерфейс.** Тёмная сине-серая тема, кольцо обратного отсчёта, плавные анимации. Когда окно спрятано в трей, анимации останавливаются и не нагружают процессор.

## Установка

### Готовая сборка

1. Откройте раздел [Releases](../../releases) и скачайте последний `ShutdownTimer-win-x64.zip`.
2. Распакуйте архив в любую папку, например `C:\Programs\ShutdownTimer`.
3. Запустите `ShutdownTimer.exe`.

Установка .NET не нужна: релизная сборка содержит всё необходимое.

Чтобы программа запускалась вместе с Windows, нажмите `Win+R`, введите `shell:startup` и положите в открывшуюся папку ярлык на `ShutdownTimer.exe`.

> Файл не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае».

### Сборка из исходников

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
git clone https://github.com/Luster00/ShutdownTimer.git
cd ShutdownTimer

# запуск для разработки
dotnet run --project src/ShutdownTimer

# запуск тестов
dotnet test

# готовый exe (нужен установленный .NET 8 Desktop Runtime)
dotnet publish src/ShutdownTimer -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish

# автономный exe (~70 МБ, .NET на компьютере не нужен)
dotnet publish src/ShutdownTimer -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Результат окажется в папке `publish/`.

## Как пользоваться

1. Выберите режим: **Таймер** или **Точное время**.
2. Задайте время кнопками ▲ ▼ (их можно удерживать) или колесом мыши над цифрами.
3. Выберите действие: **Выключить** или **Перезагрузить**.
4. При желании отключите напоминания.
5. Нажмите **Запустить**. Кнопка сменится на **Отменить**.

Пока таймер запущен, настройки заблокированы. Чтобы изменить время, сначала отмените таймер.

### Настройки

Приложение запоминает последние выбранные режим, время, действие (выключить или перезагрузить) и состояние тумблера напоминаний. Они сохраняются автоматически и подставляются при следующем запуске. Запущенный таймер между запусками не сохраняется.

Файл настроек лежит здесь:

```
%AppData%\ShutdownTimer\settings.json
```

Чтобы сбросить настройки, закройте приложение и удалите этот файл. Если файл повреждён, приложение запустится со значениями по умолчанию.

Приложение запускается в одном экземпляре. Если попытаться открыть его ещё раз (например, через ярлык), вторая копия не появится, а откроется окно уже работающей.

### Трей

| Действие | Результат |
|---|---|
| Крестик в окне | Окно скрывается в трей, таймер продолжает работать |
| Двойной клик по значку | Открыть окно |
| Наведение на значок | Показывает оставшееся время |
| Правый клик → Открыть | Открыть окно |
| Правый клик → Отменить выключение | Остановить таймер (или прервать уже начатое выключение) |
| Правый клик → Выход | Закрыть приложение полностью |

Кнопка «—» сворачивает окно на панель задач, как обычно.

### Что происходит в конце

Когда время истекает, приложение выполняет `shutdown /s /t 20` (или `/r` для перезагрузки), показывает окно с кнопкой отмены и уведомление. Отмена вызывает `shutdown /a`.

Флаг принудительного закрытия программ (`/f`) не используется, чтобы вы не потеряли несохранённые данные. Если какая-то программа мешает выключению, Windows покажет обычный экран с этим сообщением.

## Тесты

Вычисления времени и настройки вынесены в библиотеку `ShutdownTimer.Core`, которая не зависит от WPF, поэтому тесты запускаются на любой системе с .NET 8 SDK:

```powershell
dotnet test
```

Тесты проверяют ближайшее время суток (сегодня и завтра, границы месяца и года), цель таймера, минимальную задержку, округление секунд, форматирование, долю кольца, циклический переход счётчиков, порядок и неповторяемость напоминаний, а также сохранение и загрузку настроек (повреждённые файлы, значения вне диапазона). Они же запускаются в GitHub Actions при каждом push и pull request.

## Известные ограничения

- Только Windows: используются WPF и системная команда `shutdown`.
- Запущенный таймер не восстанавливается после перезапуска приложения или перезагрузки компьютера.
- Таймер считает по системным часам. Если компьютер уснул, а время истекло во сне, выключение произойдёт после пробуждения.
